# Demo Asset Provenance

Created on September 10, 2026 for the local MatchXD prototype. The six original portraits below and eleven additional carousel portraits depict fictional adults and were generated using the built-in image-generation tool. They are not identity or verification evidence.

The eleven carousel assets are saved under `assets/profiles/carousel/`. Exact prompts, generated original paths, dimensions, hashes, and inspection notes are in [portrait set A](carousel-portraits-a.md) and [portrait set B](carousel-portraits-b.md). The landing uses five original portraits plus these eleven additions, one distinct person per phone. The original Sofia asset remains available to existing app profiles.

The Connected X SVG and app icons are code-native interpretations of the supplied MatchXD brand concept. The included voice introduction uses Windows speech synthesis; the video pairs that sample audio with the app icon. Neither is a recording of a profile subject.
