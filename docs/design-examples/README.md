# MatchXD Design Examples

Three visual concepts based on the supplied MatchXD logo and Connected X app icon. These are design mockups, with fictional adult profiles, not implemented screens.

- [Coral Classic](01-coral-classic.png)
- [Bold Connection](02-bold-connection.png)
- [After Hours](03-after-hours.png)

Targeted follow-up edits are recorded in [refinement-prompts.txt](refinement-prompts.txt).

| Concept | Character | Best fit |
| --- | --- | --- |
| 01 · Coral Classic | White, blush, coral, and charcoal with generous spacing | Everyday app experience |
| 02 · Bold Connection | Large typography, saturated coral, and sculptural phone compositions | Public landing page and onboarding |
| 03 · After Hours | Charcoal surfaces, warm white text, and restrained coral highlights | Dark mode |

Suggested combination: Coral Classic for the light app, After Hours for dark mode, and Bold Connection for the landing page.

These previews use the built-in image-generation tool with `public/assets/concepts/MatchXDv1.png` as the brand reference. Layouts and lettering are concept art; final implementation should use the existing vector brand assets and tested accessible colors.
