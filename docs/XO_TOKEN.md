# XO Token

One shared black coin with a white XO mark and inset white rim. The transparent PNG is saved at `assets/brand/xo-token.png` and used on web, iOS, and Android. It was generated with the built-in image-generation tool, with no CLI fallback.

The `XoToken` component displays the asset. `XoCopy` replaces standalone XO currency words with the coin in web copy. The shared `Txt` component does the same throughout the app, including balances, costs, plan details, and notices. Singular `XO` renders as the coin alone; `XOs`, `XO's`, `XO’s`, and `XO(s)` render as the coin immediately followed by visible `’s`, case-insensitively. Surrounding spacing and punctuation are preserved. The original word remains in the image's alternative text and native accessibility label; native text containers also retain the full original sentence for screen readers. The visible suffix is hidden from assistive technology so it is not spoken twice. Neither `MXO` nor `XOXO` is a currency match. Explicit coin layouts show the amount alone and keep the currency in an accessible label.

Prior token validation, before the plural-suffix refinement: TypeScript passed. The 1254 × 1254 PNG has transparent corners. Desktop and 390px mobile browser checks confirmed 42 loaded coin images from one asset, inline currency placement, and simultaneous pricing-card/button fill on keyboard focus. A fresh page check showed no new console errors or warnings. Native integration was source-reviewed and type-checked; no native simulator was run. The plural-suffix refinement was source-reviewed and passed TypeScript, with no additional tests, build, or browser checks.

## Generation Prompt

Use case: logo-brand. Asset type: a single production-ready app currency icon for MatchXD XOs. Create exactly ONE circular coin/token, straight-on orthographic view, centered, on a truly transparent background with alpha. The whole design is strictly black and white. Flat solid near-black circular disc (#111111); a thin crisp white inset circular rim; centered bold white geometric uppercase lettering exactly "XO" (one X followed by one O), equal height, balanced spacing, softly rounded stroke ends, large enough to read at 18–24 px icon size. X is two clean crossing diagonal strokes; O is a clean circular ring. Keep the silhouette perfectly circular and its edges crisp, with generous readable letter shapes. Coin should occupy nearly all the square canvas with only 3% transparent margin. Flat graphic brand mark, elegant minimal app icon, no perspective, no tilt, no 3D bevel, no drop shadow, no metallic texture, no gradients, no decoration beyond the thin rim and XO. No other text, no labels, no board, no variants, no mockup, exactly one coin. Transparent pixels outside the circle.
